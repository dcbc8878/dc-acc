## กติกา: รหัสผ่านที่ลูกค้าแต่ละรายต้องมี (RD/DBD/SSO)

หน้ารายการลูกค้าจะเตือน (ขาด ...) ต่อท้ายชื่อ ถ้ารหัสผ่านที่ "ต้องมี" ยังกรอกไม่ครบ
เกณฑ์ว่าใครต้องมีอะไรบ้าง (ดู `missingCredsNote()` ใน `crm/index.html`):

- **RD e-Filing** — ต้องมีทุกราย ไม่มีข้อยกเว้น
- **DBD e-Filing** — ต้องมีทุกราย **ยกเว้น** ลูกค้าประเภท "บุคคลธรรมดา" (ไม่มีการจดทะเบียนนิติบุคคล จึงไม่มีบัญชี DBD e-Filing)
- **SSO** — ต้องมีเฉพาะลูกค้าที่ขึ้นทะเบียนนายจ้างประกันสังคมแล้วเท่านั้น (`has_sso = true`) ถ้ายังไม่ขึ้นทะเบียน ช่อง SSO ในหน้ารหัสผ่านจะถูกปิด (สีเทา กรอกไม่ได้) และจะไม่ถูกนับว่า "ขาด"

กติกานี้ใช้ทั้งในหน้ารหัสผ่าน (เปิด/ปิดช่องกรอก) และหน้ารายการลูกค้า (แจ้งเตือนขาด) — ถ้าจะเพิ่มเงื่อนไขแบบนี้ให้รหัสผ่านหมวดอื่นในอนาคต ให้ทำตามรูปแบบเดียวกัน
