🔗 บัญชี CRM

ล็อกอินด้วยอีเมล/รหัสผ่านเดียวกับระบบ CRM เพื่อดึงชื่อ-บทบาทจริงมาใช้ และเลือกลูกค้าจริงตอนสร้างนัดหมายได้ — ไม่มีบัญชีก็ใช้แอพโหมด Local ต่อได้ตามปกติ ไม่บังคับ

🎨 รูปแบบการแสดงผล

ธีมและค่าเริ่มต้นของปฏิทิน

🔗 Google Calendar

ซิงค์กิจกรรมจาก Google Calendar (ต้องสร้าง OAuth Client ID ของตัวเองใน Google Cloud Console)

🔗 Microsoft Outlook

ซิงค์กิจกรรมจาก Outlook Calendar (ต้องลงทะเบียนแอปใน Azure Portal เพื่อรับ Client ID)

📤 ส่งออก / iCal

ดาวน์โหลดปฏิทินเป็นไฟล์ .ics เปิดได้กับ Google/Outlook/Apple Calendar
ลิงก์ iCal แบบสด (auto-sync) จะใช้งานได้เมื่อเปิดระบบ login ส่วนกลาง (Supabase) — ยังไม่เปิดใช้งานในโหมด Local ตอนนี้

🔑 API Keys

สำหรับเชื่อมต่อบอท LINE (น้องบัญชี) ผ่าน Supabase Edge Function — ต้องเปิดระบบ login ก่อนจึงจะออกคีย์ได้จริง

🏢 โครงสร้างสิทธิ์ผู้ใช้งาน

มาตรฐานกลางของสำนักงานบัญชี (อ้างอิงเท่านั้น — จะบังคับใช้จริงเมื่อเปิดระบบ login ส่วนกลาง)

💾 ข้อมูล

ข้อมูลทั้งหมดเก็บในเบราว์เซอร์นี้เท่านั้น (localStorage) — สำรองไว้กันข้อมูลหาย
